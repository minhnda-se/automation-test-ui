Analyze $ARGUMENTS. Read the relevant requirement docs and/or source files, then report:

- What currently exists (flows, elements, actions, or code involved)
- Gaps or ambiguities that would need clarifying before implementation
- Which existing skill (if any) in `.claude/skills/` fits this work

Do not write or modify any files during this command — analysis only.
